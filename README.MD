# ATM Simulation System

A simple ATM Simulation System built using Core Java as a class project. The program runs in the terminal and allows users to create accounts, log in with a password, check their balance, deposit money, and withdraw money.

## Features

- Create multiple user accounts
- Set a password for each account
- Login authentication
- Check account balance
- Deposit money
- Withdraw money
- Logout and exit options
- Basic input validation

## Technologies Used

- Java
- Scanner class for user input
- ArrayList for storing accounts
- Object-Oriented Programming (OOP) basics

## How to Run

**1. Clone the repository**

```bash
git clone <your-repository-url>
cd <repository-folder>
```

**2. Compile the program**

```bash
javac main.java
```

**3. Run the program**

```bash
java main
```

## How It Works

1. Select **Create Account** to register with a name and password.
2. Select **Login** and enter your credentials.
3. Choose an ATM operation from the menu.
4. Select **Logout** when finished or exit from the main menu.

## Concepts Covered

- Classes and Objects
- Constructors
- ArrayList
- Conditional Statements
- Loops
- User Input with Scanner
- Basic Authentication
- Encapsulation concepts through grouping account data in a class

## Limitations

- Account data is stored in memory and is lost when the program exits.
- Passwords are stored as plain text.
- This is an educational simulation, not a real banking application.

## Project Purpose

This project was created for a Core Java class to practise basic Java programming and object-oriented concepts through a simple, interactive ATM simulation.
